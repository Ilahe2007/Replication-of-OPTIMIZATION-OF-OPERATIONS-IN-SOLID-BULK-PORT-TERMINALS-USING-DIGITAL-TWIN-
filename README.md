# Optimization of Operations in Solid Bulk Port Terminals Using Digital Twin

## Overview

This project replicates the approach presented in the research paper *Optimization of Operations in Solid Bulk Port Terminals Using Digital Twin*.

The project focuses on simulating port terminal operations and optimizing ship scheduling using an Ant Colony System (ACS) algorithm.

## Project Objectives

- Simulate solid bulk port terminal operations using a digital twin approach.
- Model key processes, including train unloading, stockyard stacking, and ship loading.
- Implement the Ant Colony System algorithm from scratch to optimize ship sequencing.
- Compare the performance of the optimization approach across four scenarios against a baseline.

## Methodology

### 1. Digital Twin Simulation
A Python-based simulation models the main operations of a solid bulk port terminal, including the movement and handling of bulk materials.

### 2. Ant Colony System (ACS)
The optimization algorithm was implemented from scratch, including:
- Pheromone management and updates.
- Pseudo-random-proportional transition rules.
- Solution construction and optimization.

### 3. Performance Evaluation
Four scenarios were evaluated and compared against a baseline to examine the effectiveness of the optimization approach.
